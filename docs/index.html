A Jatekrol

A Console UNO a nepszeru UNO kartyajatek egy terminalos, interaktiv implementacioja. Kifejezetten a palyavalasztasi nyilt napra keszult, hogy bemutassa a 7. es 8. osztalyos diakoknak, mit lehet megvalositani C# es .NET 10 segitsegevel.

Szines ASCII kartyak, nyilakkal vezerelheto interaktiv kezvalasztas, beepitett 8-bites retro hanghatasok, mesterseges intelligencia elleni jatek es tobbjatekos mod varja a jatekosokat.

Fobb Funkciok

ASCII Kartyagrafika

Tobbsoros, szines kartyadobozok egyertelmu szimbolumokkal (X = Kimaradsz, <> = Fordito, +2, +4, W = Vad).

Nyilakkal Vezerelheto Kez

A Balra es Jobbra nyilakkal bongeszheted a lapjaidat, ENTER-rel lerakhatod oket. 7 lap felett dinamikus lapozas mukodik.

8-Bites Retro Hangok

Beepitett chiptune szintetizator: laplerakas, kartyahuzas, akciohangok, UNO riasztas es gyozelmi zene.

Magyar Nyelvu Kezelofelulet

A jatek alapertelmezetten magyarul indul, a diakok azonnal ertik a szabalyokat es a menupontokat.

Hivatalos UNO Szabalyok

Pakli ujrakeverese a dobopaklibol, egyszeri akciohatasok, szabalyos 2 fos Fordito-kimaradas es UNO figyelmeztetes.

Beallitasok Mentese

A kivalasztott beallitasok (hangero, nyelv, zene) automatikusan elmentodnek a gepeden.

Iranyitas a Jatekban

Gombok es Parancsok:

  • ← / → : Lap kivalasztasa a kezben
  • ENTER / SZOKOZ : Kivalasztott lap lerakasa
  • 1 - 9 : Lap azonnali kijatszasa sorszam alapjan
  • D : Kartya huzasa a paklibol
  • Q : Kilepes / Uj jatek

Futtatas & Docker

1. Helyi futtatas (.NET 10 SDK) 

git clone https://github.com/CsPS0/Console-UNO.git
cd Console-UNO/uno-game/uno-game
dotnet run

2. Docker Compose (Web & Terminal) 

# Web verzio inditasa (http://localhost:3000):
docker compose up -d web

# Terminalos jatek inditasa:
docker compose run --rm game

3. Szukseges Docker Image-ek (Letoltes / Pull): 

# Web szerverhez (localhost:3000):
docker pull nginx:alpine

# Konzol jatekhoz (.NET 10 Arch Linuxon / barmely rendszeren):
docker pull mcr.microsoft.com/dotnet/sdk:10.0
docker pull mcr.microsoft.com/dotnet/runtime:10.0

# Közvetlen futtatás terminalban:
docker build -t console-uno .
docker run -it --rm console-uno
